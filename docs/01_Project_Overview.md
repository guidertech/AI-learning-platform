# ClassOrbit AI - Project Overview

ClassOrbit is a premium, AI-powered student learning platform designed to make mastering academic subjects engaging, adaptive, and highly personalized. By combining a beautiful, minimalist digital workspace with an interactive conversational co-pilot named **Maya**, ClassOrbit guides students through their academic curriculum, diagnoses learning gaps, and helps recover from weak topics in real time.

---

## Brand & Visual Identity
ClassOrbit leverages a **Tactile-Digital Minimalism** aesthetic system tailored for calm focus, low cognitive load, and delightful progress:
*   **Palette**: Built on a sophisticated hierarchy of purples (Primary Royal Purple `#5341cd`, Secondary Vibrant Purple `#6b38d4`) against a bright canvas of pure white and soft light purple (`#f8f9ff`).
*   **Typography**: Clean and systematic typography powered by **Inter** (display, body) and **Geist** (labels, technical metadata).
*   **Layout**: A mobile-first spacing rhythm utilizing a strict 24px page margin, 16px element gaps, and persistent 64px glassmorphic bottom navigation bar.
*   **Shapes**: Friendly geometry featuring generous 20px rounded corners on containers and cards, paired with smooth ambient drop shadows (`rgba(83, 65, 205, 0.12)`).

## Key Features & Student Flow

### 1. Onboarding & Personalization
Students begin by configuring their grade, learning style, and target focus. This constructs their initial profile, which the AI engine uses to calibrate its conversational difficulty, vocabulary, and problem complexity.

### 2. Adaptive Learning Dashboard
The home screen serves as the launchpad for a student's daily study session:
*   **Daily Goals & Timeline**: Monitors total study time (e.g., 42/60 minutes) in a visual progress ring.
*   **AI Recommendations**: Offers context-aware, next-step recommendations based on past quizzes and weakness areas (e.g., "Ready to tackle Quadratic Equations?").
*   **Quick Shortcuts**: Instant access to primary app sections (Learn, Practice, AI Tutor, Progress Analytics).

### 3. Interactive AI Learning Workspace
The workspace is the heart of the learning experience, housing the conversational AI tutor, **Maya**:
*   **Chat Workspace**: Interactive panel where students can ask questions, receive step-by-step breakdowns, and receive encouraging prompts.
*   **Visual Recovery Modules**: Custom interactive widgets built to address specific core weaknesses. For example, a fraction recovery canvas demonstrating fraction cuts (halves, quarters) using clean 3D illustrations.

### 4. Topic Quizzes & Mastery Checks
To track retention, the platform features multiple check-in levels:
*   **Topic Quizzes**: Standard multi-step practice questions with visual feedback.
*   **Mastery Checks**: Adaptive evaluations designed to test comprehensive understanding of a module.
*   **Weakness Diagnosis**: Detailed assessments that isolate specific mathematical components (e.g., dividing mixed numbers vs. multiplying fractions) that are causing difficulty.

### 5. Learning Journey & Analytics
A comprehensive profile section tracking historical performance:
*   **My Learning Journey**: An interactive milestone timeline demonstrating completed chapters, badge awards, and upcoming topics.
*   **Progress & Analytics**: Detailed desktop statistics showing weekly study time, accuracy trends, and module completion percentages.
